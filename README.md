**How to Use**

Open The Installer
Press Install
Select Fonts and Cursors Of Your Choice Or Upload Your Own
Press Finish

Restart/ Shut down Your PC

If It Freezes At Anytime DO NOT Close It.



**Info**



Report Bugs In The Comments

When you press finish, if the cmd window does not go away just close it.

To add custom Cursors create a folder like this:

Folder
- ArrowCursor.png | Select
- ArrowFarCursor.png | Normal
- IBeamCursor.png |Typing
